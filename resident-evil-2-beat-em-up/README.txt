RESIDENT EVIL 2: BEAT EM UP

An unofficial, fan-made HTML5 arcade brawler.

PLAY
Upload every file in this folder to a normal static web host, keeping the
relative paths intact, then open index.html in a modern browser. No external
runtime services or downloads are needed. HTTP hosting is the recommended mode.

CONTROLS
WASD / Arrow keys: move
J: knife combo
K: roundhouse kick (brief recovery between kicks)
L: fire handgun
Space: dodge
R: reload
Escape / P: pause
M: mute
Touch screens: movement joystick and action buttons appear automatically.

CAMPAIGN
Five chapters, each with three continuous areas. Clear the active area and move
right to continue. Each chapter ends with a boss. New chapters restore health
and ammunition. Continue restores the latest chapter checkpoint on this device.
Retry Chapter restarts that chapter and its starting score. A new game starts
a new campaign. Local storage is optional; play still works when it is blocked.

Break scenery supplies for herbs and ammunition. Herbs stay on the floor when
health is full. Orange warnings signal incoming attacks; dodging gives a brief
window of protection. Boss attacks cannot be interrupted once telegraphed.
