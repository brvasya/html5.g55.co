Half-Life 2: Platformer

Upload every file in this archive to the same hosting folder, preserving the assets/ and fonts/ directories. Open index.html through your website. The game works from the domain root or an ordinary subfolder and has no external runtime dependencies.

Controls
A/D or left/right arrows: move
Space, W, or up arrow: jump; release early for a shorter jump
J/Z: crowbar
K/X: fire SMG
R: reload (unlimited reserve ammunition)
L/C/E: grab or throw a nearby prop, or fire a gravity pulse
Esc/P: pause
M: mute
F: fullscreen where supported

Touch controls appear on phones and compact windows. Tap the ammo counter to reload.

Five chapters, two checkpoints per chapter, and a final Strider encounter. Continue preserves the active run; local storage remembers the current chapter between sessions. Start Game begins a new campaign.

Direct file:// launching has not been browser verified. Use a normal HTTP web server.

This is an unofficial fan game. Local font licensing is included in fonts/LICENSE.txt.
